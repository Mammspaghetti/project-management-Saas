# TaskFlow — frontend

SPA React 19 + TypeScript (Vite). Voir l'architecture dans [../docs/architecture.md](../docs/architecture.md).

```bash
npm install
npm run dev      # http://localhost:5173 — /api est proxifié vers http://localhost:8080
npm test         # Vitest
npm run lint     # oxlint
npm run build    # tsc + build de production
```
